# 红色球体 / 方块目标识别 + 白平衡与二维色偏

基于本次提供的 **lab_wb_shift_DSI_SC500_7inch.zip** 修改。保留自动白平衡实际增益显示、手动 K 值/二维色偏、感光度、触摸交互、原 CSI 黑屏修复和帧缓存保护。适用 PH1P35MDG324 + SC500CS + 1024×600 DSI/GT911。

## 下载与开启

1. 整包解压到短英文路径，例如 `C:/FPGA/shape`。
2. 下载根目录 **DSI_SHAPE_SC500_7inch_compress.bit**；也提供普通 `.bit`。不要继续使用旧 WB_SHIFT / RED_TARGET 镜像验证新功能。
3. 实时画面长按约 0.8 秒 → 白平衡设置 → 自动白平衡 → **目标识别 / 开启**。
4. 回退到完整预览，将一个红色球体或方块放入浅色、干净背景中。建议目标宽高至少 64～80 个显示像素，光照均匀，物体轮廓完整。

开关默认关闭，触摸位置及原有开启/关闭交互保持不变。切换预设或手动白平衡时暂停识别，回到自动模式恢复所记忆的开关状态。

## 识别及画面标注

- 球体：`RED BALL ( 511, 299)`。
- 方块：`RED CUBE (...)`，考虑正面以及一定旋转/透视角度下的直边投影。
- 红色目标存在、类别证据不足：`UNKNOWN (...)`，仍显示外接框和中心十字。
- 无目标：画面下方中央附近显示 `NO TARGET`，取消框和十字。

标签采用红底白字，优先放在目标框上方，靠近上边缘时改放下方，接近右边缘时向左收回。设置页会避开右侧 UI 面板。继承黑色 3 像素外接框和中心十字，不再使用固定左上角的识别结果面板。

坐标以 **1024×600 屏幕有效图像左上角**为原点；X 向右、Y 向下。中心取外接框中心并向下取整。现有 1280×720 中心裁剪保持不变，换算至原始图像时 X 加 128、Y 加 60。结果对应上一显示帧，移动时通常滞后一帧，初次出现需连续两个完整帧。

本版沿用一个主要红色目标的范围，不提供球体和方块同时出现时的独立多框识别，也不提供三角形类别。测试中的三角形显示 UNKNOWN。

## 实现方法

红色分割 → 短游程去噪 → 区域坐标/面积及每行轮廓描述 → 消隐期形状特征和直边拟合 → 整帧类别锁存 → 目标旁 OSD → 原有 UI/DSI。

球体同时检查近圆比例、轮廓宽度模板和持续曲线；方块检查凸的直边投影以及区域填充、比例和平衡。没有只用面积比或宽高比把所有红色区域强分为两类。尺寸小、边缘截断或轮廓不足时降为 UNKNOWN。

这是单目外观分类，不能证明物体具有三维体积。相同投影的红色圆片、方形纸片等也可能得到同一类别；强光、高光、深阴影、遮挡和同色背景可能影响结果。需要用实物红球和方块上板复测，仿真结果不代表摄像头场景识别率。

详细流程、参数与边界见 [形状识别说明](docs/SHAPE_RECOGNITION.md)。保留功能的操作见 [白平衡和二维色偏说明](docs/WB_SHIFT_REFERENCE.md)。

## 源码入口

相对 `user_source/hdl_source/`：

| 文件 | 内容 |
|---|---|
| `target/red_shape_classify.v` | 行描述 RAM、近圆模板、凸轮廓直边分析和 BALL/CUBE/UNKNOWN |
| `target/red_target_detect.v` | 原有红色区域统计/确认，新增每行描述写入 |
| `target/red_target_video.v` | RGB 判定、类别整帧锁存、跟随目标的标签、黑框与十字 |
| `target/target_ascii_font.v` | 英文类别、坐标及标点字模 |
| `ui/wb_ui_overlay.v` / `wb_ui_font.*` | “目标识别”“球体或方块”中文界面 |

顶层、ISP/AWB/色偏算法、触摸控制、相机寄存器、DDR/DSI 和时序约束均保留本次基线。新增模块在三个 TD 工程清单中登记。仅存储每行 34 位描述，共 20,400 位，没有新增整帧 RGB 缓存。
