# 保留暗部与适度增色修正版验证

## 实现与范围

仍只有原图与图示效果。针对上板照片中暗部细节被量化吞掉和过强增色的问题，
移除两模式的固定黑点截断；风格改为暗部不量化、较细的中亮部色阶、共同 RGB 提亮、
1.25 倍色差和柔和轮廓。原始相机寄存器、白平衡、传输与显示链路未改。
完整顺序与整数公式见 README.md、enhance_model.py 和 RTL。

## 本轮实际执行 11 项测试

- 四种小尺寸共 60 帧：像素、模式边界、SOF/EOL、随机空拍、RGB/灰阶和打包字精确比较。
- 720p 人像原图／图示效果，共 1,843,200 像素、345,600 个打包字，逐项匹配独立 NumPy 参考。
- 街景两模式共 174,496 像素，真实 RTL 捕获与参考逐字节一致。
- 亮度与色彩测试六帧共 245,760 像素：0～31 暗灰阶在两模式保留全部 32 种输出，
  黑白端点、中性灰、八种色系和四种肤色色块通过。
  正常亮度加独立 -8～8 噪声、1/8 亮度加独立 -2～2 噪声；
  14 个灰色／彩色／肤色平坦区的相邻像素平均跳变均低于输入。
  这不等于所有真实纹理区域均能达到同一降噪指标。
- 人像数字亮度 1、1/8、1/32 三帧共 172,800 像素，精确匹配；
  人像区域保留至少五种亮度。这是参考图的数字缩放，并非实体相机 RAW 或实拍观感预测。
- 中断帧、切换模式和复位，未泄漏旧行或旧流水数据。
- 输入时钟末次传输后立即暂停，720p 两帧完整发布；A/N/E=38400，P=2A300，345,600 字提交。
- 24MHz 联合显示、DDR ready 暂停 3500 拍，四帧发布，零丢字，65,536 个白色显示检查像素无黑点。
- 三份工程配置 270 个文件引用，243 个原始源/IP 文件字节保留。

另沿用 11 项协议与诊断测试：本轮核对全部相关源码 SHA256 一致，未冒充本轮重跑。
详见 inherited_verified_tests.json。测试不模拟物理 DDR、MIPI/DSI 电气特性或完整 ISP 的实拍颜色。

## 仍需实体确认

未连接用户的摄像头和显示屏，不能声称上板效果已达标或旧黑屏已经消除。
现场原图中的局部亮斑可能包含反光或高亮裁剪，屏幕照片不足以区分；滤镜不能恢复已经丢失的采集信息。
相机仍为手动曝光／增益，本版未新增自动曝光或时域降噪。
使用 TOUCH_STYLE_BALANCED_compress.bit，在同一场景对照两模式及补光变化。
自行编译请使用根目录 BUILD_STYLE.ps1；仅在 TD 图形界面打开 .al 不会自动执行脚本的额外物理修正。
