# 原图／图示效果：保留暗部与适度增色修正版

适用 HX1P35A / PH1P35MDG324 -3、SC500CS 和原 7 寸 DSI 触摸屏。
本版对应用户上板照片中“补光后失色、不补光时大片灰块”的反馈。
仍只有原图与图示效果两种模式。未调整摄像头曝光、模拟增益、白平衡或显示屏参数。

## 下载和操作

BitWriter 下载工程根目录的 `TOUCH_STYLE_BALANCED_compress.bit`。
KEY1 复位后默认原图；点按并松开切换图示效果，再点按返回。
先在用户此前拍摄的同一场景和光照下对照两种模式，再对照补光场景。

## 本次修正

旧版处理包含黑点截断、12 级亮度量化、16 步色度量化、三倍色差和额外去白。
这些操作会吞掉暗部弱纹理，放大彩色噪声，并把部分通道裁剪到零。
此次上板原图仍可辨认人脸与衣服，效果模式却大量丢失细节，因此先修正颜色算法。
屏幕照片不是相机原始数据，无法据此精确测出传感器曝光、光源色温或屏幕的数值响应。

| 处理 | 本版变化 |
|---|---|
| 原图 | 去掉黑点 12、白点 248 的硬拉伸，改为零黑点 Gamma 0.95；保留原有轻微色度校正和四拍延迟 |
| 空间降噪 | 保留两级既有 3×3 保边平滑，保护明显轮廓，不增加 DDR 全帧遍历 |
| 边缘检测 | Sobel，阈值改为 64／128／256；轮廓分级保留亮度 1、31/32、15/16、7/8 |
| 颜色量化 | Y<32 保留每个亮度和色度代码；其余亮度最近 8 步、色度最近 4 步 |
| 暗部提亮 | 量化解码后按最大 RGB 通道查询共同增益，三个通道共用同一倍率；最大 2.5 倍 |
| 全色系增色 | 最大通道锚定的 1.25 倍色差，去掉旧版三倍色差和公共去白偏移 |

显示链路仍为：

**MIPI → RAW10 解包 → ISP／保边平滑 → Sobel 边缘检测 → 颜色量化与轮廓融合 → DDR2 → DSI**

算法采用所有颜色相同的规则，没有单独增强红色或蓝色。
原图不做空间平滑、色块量化和轮廓处理。

共同增益的定点公式：最大通道 M=0 时输出仍为零；M>0 时
`G = min(640, round(256 × (255/M)^0.2))`，各通道为 `(C×G+128)>>8`。
随后适度增色：`max(0, C-floor((max(R,G,B)-C+2)/4))`。
中性灰、白、黑保持中性。暗部不再因为固定黑点被整片截掉。
有限的输入位深、噪声及局部平滑仍会限制细节，不能恢复采集前已经丢失的信息。

## 重新生成比特流

查看工程可打开 `enhance_project/lab_touch_style_balanced.al`，顶层 `enhance_top`。
**与本次交付相同的完整编译入口是根目录 `BUILD_STYLE.ps1`。**
在解压后的工程根目录打开 PowerShell，运行：

```powershell
.\BUILD_STYLE.ps1
```

TD 6.2.1 默认安装目录为 `C:/Anlogic/TD_6.2.1_Engineer_6.2.168.116`。
可使用 `-TdHome` 或 `-LicenseFile` 指定本机路径。
脚本使用新建短临时目录执行完整综合、布局布线，并在需要时进行额外物理优化和保持修正。
只有最终 SWNS、HWNS 均非负时，才更新根目录的 `TOUCH_STYLE_BALANCED*.bit`。
若脚本报错，请检查临时目录报告；根目录旧 bit 不代表本次编译成功。
直接在 TD 图形界面点击生成使用的是 `.al` 的默认策略，不会自动执行脚本里的附加修正。

`VALIDATION.md`、`DELIVERY_MANIFEST.json` 和 `evidence/` 记录本次实际执行的测试与最终时序。
