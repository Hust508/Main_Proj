# 上滑唤出半透明工具栏：已确认方案

状态：**用户已确认推荐方案，现已在 `D:/FPGA/Main_Proj` 实现。** 当前功能见 [实施说明](UI_DESIGN_AND_IMPLEMENTATION.md)，原上滑 UI 的构建结果见 [TD 构建报告](UI_SWIPE_BUILD_REPORT.md)。以下保留原方案参数供追溯；现在工具栏已增设 ART 卡通按钮。

## 可行性与画面比例

当前视频仍按既有链路从 1280×720 摄像头画面中心裁剪成 1024×600；固定工具栏只是在最后一级把底部 96 行像素覆盖，并没有把视频压缩成较矮的区域。改为“默认隐藏、呼出后半透明叠加”可以让平时的 1024×600 画面完整可见，菜单打开时也能透过面板看到原视频；摄像头采集、DDR、裁剪、帧率和 DSI 时序不变。若目标是显示完整 1280×720 视野及严格 16:9 比例，则属于另一项缩放或黑边设计，需要单独确定。

## 已确认的交互参数

| 项目 | 推荐值与行为 |
|---|---|
| 初始状态 | 上电隐藏工具栏；视频完整显示。 |
| 唤出 | 单指从屏幕底部 `y>=500` 开始向上滑动，纵向位移至少 100 像素、水平偏移不超过 80 像素，1 秒内完成。手指松开后菜单显示；本次手势不触发功能按键。 |
| 面板 | 高 150 像素（屏幕的 1/4），覆盖 `y=450..599`；不挤压、不缩放原图。背景及按钮用约 50% 视频 + 50% 界面色混合，文字及细边框保持清晰。 |
| 按键 | RAW / EDGE / OSD 三个大按键，位于面板内；仅在菜单显示时有效。按下并松开且移动不超过 20 像素才算一次点击，长按、拖动、多指不切换。选中高亮对应实际显示的视频模式。 |
| 收起 | 菜单内单指向下滑动至少 80 像素，或轻点面板外的视频区域。选择模式后菜单保留 3 秒供连续比较，然后自动收起；任何操作重置计时。 |
| 刷新边界 | 显示/隐藏状态在视频帧边界切换，避免半帧出现或消失。原有 RGB/VS/HS/DE 对齐延迟保持不变。 |

## 实现路径

1. `gt911_touch.v` 对每次成功读取并清除状态的报告输出一个有效脉冲，同时给出连续单指 X/Y；保留原有 I²C 错误重试和复位时序。
2. 新增触摸界面控制器：统一做坐标方向变换、单指起点/位移判断、释放消抖、菜单显示状态和三按键命令。滑动唤出与点击命令互斥，避免上滑经过按键时误选。
3. `dsi_menu_overlay.v` 接收菜单显示状态，隐藏时逐像素透传视频；显示时在 `y=450..599` 对每个 RGB 通道做固定比例混合。工具栏放在既有动态 OSD 之后，保持视频通路和输出时序。
4. 更新 TD 工程文件、仿真测试、设计说明，运行 TD 完整构建和最终时序检查；生成新位流后再按你的发布要求决定是否推送。当前版本全局建立裕量只有 +0.006 ns，新布局布线必须重新验证。

## 已确认的两点

1. 采用 **150 像素高、50% 透明度、底部起滑、3 秒自动收起**。
2. 保持当前 1024×600 全屏视频的采集/裁剪链路，解决固定工具栏遮挡；不改变摄像头原始 1280×720 到屏幕的现有中心裁剪方式。
