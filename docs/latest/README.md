# 统一版 UI、滤镜与目标功能设计/开发文档

## 现有功能与舍弃功能

### 当前已实现

- **Hproject 风格的主界面**：预览页长按约 800 ms 打开设置；预览顶部 `y<64`、底部 `y>=548` 叠加约 25% 亮度的黑色透明效果；设置页在右侧 `x>=560` 覆盖深色面板，左侧继续显示实时视频。
- **摄像头参数页**：自动白平衡、环境预设、手动色温、B/A 与 G/M 二维色偏、1/2/4 倍快捷感光度及细调。
- **滤镜库**：原图、黑白、动漫、负片、像素画、Sobel 边缘六种实时效果，并保留完整摄像头到屏幕链路。
- **功能库**：可独立开启 `FPGA VISION` 水印标签；可开启红、绿、蓝中单一主目标的跟踪、外接框、中心点和 BALL/CUBE/UNKNOWN 外观分类。
- **统一滤镜底层**：所有滤镜接入 `image_filter_bank_96`，共享 96 位/拍、四像素并行接口、帧边界模式锁存和同一侧带延迟，减少各算法重复的模式切换与同步代码。
- **可构建产物**：TD 6.2.1 综合、布局布线、最终时序和 bitstream 生成均通过。

### 合并时舍弃或替换

- 舍弃 Yproject 的“底部上滑唤出、3 秒自动隐藏”工具栏，统一采用 Hproject 的“长按进入、右侧分页、逐级回退”交互。
- 舍弃 Yproject 旧的 RAW/EDGE/OSD/ART 四按钮布局；EDGE 和 ART 能力转入滤镜库，RAW 对应“原图”。
- 舍弃旧 OSD 中动态 Anlogic 图标/计数器，改成可独立开关的固定 `FPGA VISION` 水印标签。
- Hproject 原“仅红色目标”替换为红/绿/蓝主色自动选择，但仍是**单一主目标**，没有多目标连通域、通用物体检测或三角形类别。
- Hproject 和 Yproject 的阶段目录、历史压缩包及历史 bitstream 继续保留用于回溯；它们没有参与当前 `project/` 的编译。

### 当前限制

- 目标算法是基于颜色阈值、区域轮廓和几何特征的实验功能，BALL/CUBE 表示二维外观分类，不能证明物体具有三维体积。
- 跟踪每帧选择红、绿、蓝像素数量最多的一类，只输出一个框；颜色选择和确认会带来约 1～3 帧响应延迟。
- 黑白和边缘滤镜会移除颜色信息，负片会改变颜色含义；RGB 目标功能建议在原图模式下使用。
- DSP 使用量为 40/40，后续增加乘法密集算法前必须优化或复用 DSP。
- 当前机器没有 Vivado，更新后的 RTL 仿真回归未重跑；TD 全流程已通过，实物摄像头与触屏仍需上板确认。

## 2. 视频链路

```text
SC500CS / MIPI CSI-2
  -> RAW10 解包与去马赛克
  -> 白平衡 / 二维色偏 / 亮度补偿
  -> image_filter_bank_96
  -> 128-bit 打包 / DDR 帧缓存
  -> 1280×720 中心裁剪为 1024×600
  -> RGB 主目标框与文字
  -> Hproject 风格 UI / 水印
  -> MIPI DSI 屏
```

采集和存储仍采用 1280×720；显示端沿用中心裁剪，偏移约为 `(128,60)`。UI 是显示末端的像素覆盖层，不会压缩视频或改变比例。

滤镜选择在摄像头时钟域通过 `config_mailbox` 同步，并只在帧起点锁存。`video_in` 把 3 位模式写入对应 DDR 槽位，`video_out` 在显示帧开始时取回模式，给后续显示状态扩展保留可靠依据。

## 4. 滤镜库设计

`image_filter_bank_96` 输入/输出均为每拍四个 RGB888 像素。黑白、像素画、边缘及原图延迟统一为一拍；动漫和负片使用同一拍的颜色/边缘结果。选择器只切换并行结果，不为每种滤镜复制帧控制。

| mode | 名称 | 算法 |
|---:|---|---|
| 0 | 原图 | 白平衡和亮度处理后的 RGB 直通 |
| 1 | 黑白 | `Y=(77R+150G+29B+128)>>8`，移位加法实现 |
| 2 | 动漫 | RGB 四级量化；Sobel 边缘位置覆盖深色描线 |
| 3 | 负片 | RGB 逐位反相 |
| 4 | 像素画 | 8×8 块采样、RGB332 量化、最近邻复用 |
| 5 | 边缘 | 两行缓存的近似 Sobel，二值黑白输出 |

关键文件：

- `project/user_source/hdl_source/isp/image_filter_bank_96.v`
- `project/user_source/hdl_source/isp/rgb_to_gray_96.v`
- `project/user_source/hdl_source/isp/cartoon_stylize_96.v`
- `project/user_source/hdl_source/isp/pixel_art_96.v`
- `project/user_source/hdl_source/isp/edge_detect_96.v`

新增滤镜时应接入现有 96 位接口并匹配一拍输出延迟；模式编号扩展后同时更新 UI、配置总线、DDR 槽位标签和测试台。

## 5. 功能库设计

### 5.1 水印

水印开关位于功能库。开启后预览页顶部显示 `FPGA VISION`，使用 UI 字模 ROM 绘制，与视频共用顶栏暗化背景。水印不占用视频帧缓存，也不改变画面尺寸。

### 5.2 RGB 主目标及形状

`rgb_target_video` 对显示端 RGB 进行红、绿、蓝优势色判定，每帧分别统计三种候选像素数。下一帧使用上一帧数量最多的颜色作为当前目标色，再复用一套区域和形状分类器：

```text
RGB 优势色阈值
  -> 每帧主颜色选择
  -> 短游程去噪
  -> 单一区域边界、面积、行轮廓
  -> 近圆模板 / 凸轮廓直边特征
  -> BALL / CUBE / UNKNOWN
  -> 黑色框、中心十字、彩色标签和坐标
```

标签首字母 `R/G/B` 表示当前选中的颜色，如 `G BALL (511,299)`。没有有效目标时显示 `NO TARGET`。类别不足时仍显示框和 `R/G/B UNKNOWN`。

这是“尚不成熟的目标跟踪”实现：没有连通域列表或多框输出；同色背景、反光、阴影、遮挡、过小目标、快速移动以及多个彩色物体都会影响结果。建议用哑光纯色球/方块、浅色背景、均匀光照进行测试。

## 6. 配置总线

系统域到显示域的 UI 邮箱扩展为 39 位，整帧快照后再送入目标层和 UI 层。

| 位 | 字段 |
|---|---|
| 38 | 实体键控制轴 |
| 37:33 | B/A 色偏 |
| 32:28 | G/M 色偏 |
| 27 | 目标跟踪使能 |
| 26 | 水印使能 |
| 25:22 | UI page |
| 21:20 | 白平衡模式 |
| 19:18 | 预设 |
| 17:11 | 色温索引 |
| 10:4 | 感光度 |
| 3:1 | 滤镜模式 |
| 0 | 触屏在线 |

白平衡仍使用独立 19 位邮箱，滤镜使用独立 3 位邮箱进入 CSI/ISP 时钟域，避免一个功能的扩展改变另一个算法的数据路径。

## 8. 上板验收清单

1. 下载压缩统一版镜像，确认摄像头画面稳定且比例与旧工程一致。
2. 长按预览 0.8 秒，检查设置面板、回退和六个原参数页面。
3. 逐个选择六种滤镜，确认下一完整帧切换、无花屏和无错误模式标签。
4. 开关水印，确认只影响顶栏标签。
5. 在原图模式分别放置红、绿、蓝球体和方块，检查颜色字母、框、中心和坐标。
6. 用三角形、同色背景、多个目标和小目标测试 UNKNOWN/单目标边界。
7. 复测自动白平衡、四个预设、手动色温、色偏、感光度和实体按键。
