# 预览与诊断页面

## 页面操作

预览页（page 0）保留简洁的 `延迟 N 帧` 状态和原有模式提示，不增加占用画面的统计面板。单指固定长按约 800 ms 进入设置页（page 1）；点击底部 `诊断信息`（x=584～999，y=504～555）进入 page 9。左上角 `回退` 返回设置页，再次回退返回预览。

诊断页沿用设置页右侧面板，左侧摄像头画面继续播放，1024×600 裁剪与比例不变。所有读数按显示帧锁存，避免数字在一帧内变化。

| 项目 | 来源和含义 |
|---|---|
| 当前帧龄 | 摄像头当前 SOF 序号减正在显示的 DDR 帧序号；未有有效画面时显示 `---`。颜色按 0～2 / 3～4 / ≥5 帧分级。 |
| 峰值帧龄 | 开机或复位以来已显示帧龄的最大值。 |
| 丢弃帧数 | 输入帧存储器因长度、错误或写入问题未发布的帧数。 |
| 读取溢出 | DDR 读出的数据遇到输出 FIFO 满的帧数。 |
| 显示欠读 | 显示需要像素但输出 FIFO 没有数据的帧数。 |

前三项统计来自 DDR 时钟域，使用握手邮箱送往显示时钟域。显示欠读计数产生于显示时钟域。异常计数在 255 处饱和显示；页脚提示 `计数上限255`。计数器本身仍保留原有 32 位宽，不因 UI 饱和而停止计数。峰值为 8 位帧龄的最大值，跟随现有帧龄 255 饱和规则。

此页显示的是数字链路的帧龄和异常计数。它不直接给出传感器曝光至液晶发光的端到端毫秒数；需要真实毫秒值时，须增加同一时钟基准下的硬件时间戳或外部高速摄影测量。

## 实现和验证

- `ui/wb_ui_control.v`：page 1 新入口和 page 9 回退。
- `design_top_wrapper.v`：峰值寄存器、异常计数接线及 DDR 到 DSI 的 24 位邮箱。
- `tools/wb_ui_overlay.template.v`、`tools/generate_wb_ui.py`：页面布局、数字和中文字形；生成 `ui/wb_ui_overlay.v`、`ui/wb_ui_font.*`。
- `verification/ui_test.sv`：新增页面触控导航和十页渲染路径。

板上验收：正常视频下确认当前帧龄稳定且峰值不小于当前值；制造可控的坏帧或读写压力后确认相应计数增加；复位后确认峰值和计数清零。历史 bitstream 的构建报告不代表本页已经在实板验证。
