# 白平衡视频黑屏修复版 + 感光度 UI

适用：安路 PH1P35MDG324 开发板、SC500CS 原生 1280×720 RAW10 摄像头、原例程的 7 英寸 1024×600 DSI + GT911 触屏。基于上次交付的独立白平衡 UI 工程修改，原工程和同步参考文件未被覆盖。

## 下载与打开

1. 将整个压缩包解压到较短的英文目录，例如 `C:/FPGA/wb_fix`。TD 对很长的工程路径支持有限。
2. 优先下载根目录 `DSI_WB_FIX_SC500_7inch_compress.bit`；也提供普通 `DSI_WB_FIX_SC500_7inch.bit`。
3. TD 6.2.1 打开 `td_project/wb_ui_dsi.al`。工程内部名称沿用 `wb_ui_dsi`，新镜像文件名带 `WB_FIX`。
4. 需要重建时，在工程根目录运行 `./build.ps1`；安装位置不同时用 `-TdHome` 指定。构建结果会更新根目录两个 bit 文件。

## 此版专门修复的黑屏原因

上一版 CSI 检查器把 `I_valid` 下降当作行结束；实际两 Lane 解码器在一行内部每两拍才输出一个 32 位字，因而 1→0 是正常节拍。旧检查器把这些间隔当成许多“短行”，所有完整帧都被丢弃，UI 还能正常显示，视频却一直没有可显示帧。这是上一版软件引入的错误。

本版仅修改三个活动 RTL 文件，保留既有 UI、白平衡平滑、感光度和帧缓存保护：

- `isp/csi_unpacket_2lane.v`：新增 `O_csi_line_end`，以 RAW10 有效载荷真正结束为依据，在最后一个 32 位有效字之后发出一次行结束。原图像数据和有效信号的逻辑保持不变。
- `wb/camera_frame_check.v`：只在 `I_valid` 为高时累加数据字，允许字间空拍；只在显式行结束时检查 400 字并累计行数。Lane Error 仅在有效像素负载时参与坏帧判定，避开包间空闲阶段的误触发。
- `design_top_wrapper.v`：连接新的行结束信号。

完整性校验继续启用，仍检查 400 字/行、720 行和存储侧 172800 字/帧。

之前只测试连续有效字的用例不足以模拟真实 CSI 协议。本版新增直接使用实际 CSI 解码器、RAW10 解包、去马赛克、ISP 和存储/显示 RTL 的回归，用三帧 1280×720 两 Lane 输入，比较旧/新检查器，并检查摄像头画面能通过帧缓存输出。RAM、命令 FIFO 和 DDR 时延使用行为模型，加密物理接收/发送 IP 和实物电气链路仍需上板验证。

## 操作

- 实时画面中单指固定长按约 0.8 秒进入设置；拖动、双指或触控通信异常会取消长按。
- 保留自动白平衡、环境预设、自定义色温三种模式，各页左上角均可回退。子页回设置，设置页回实时预览。
- 环境预设：暖色灯光 3000 K、日光 5500 K、阴天 6500 K、阴影 7500 K，点击后立即选中，下一个摄像头帧开始应用。
- 自定义：滑条 2500～10000 K，每格 100 K；离开后保留自定义值。
- 新的“感光度”页：1 倍、2 倍、4 倍快捷按钮；减少、增加、恢复默认；加减支持长按重复。开发板原来的两个增益按键共用同一设置，屏幕数值同步。
- 范围仍为原例程支持的实际模拟增益 1.000～5.125 倍，默认 4 倍。界面保留两位小数，最大显示 5.13 倍；每档实际步长随 1×/2×/4×粗增益区间变化。
- 该功能调整传感器模拟增益，曝光维持原来的 1990，原提亮曲线保留。倍率尚未换算为经标定的 ISO100、ISO200 等数值。

## 本次防闪烁改动

1. **修复帧头与 FIFO 复位冲突**：帧开始标记随数据进入新的异步 FIFO，只在全局复位时清 FIFO；不再每个 SOF 复位并冲掉首批像素。打包模块加入实际复位及 SOF 对齐。
2. **完整帧才能提交**：CSI 侧检查每行 400 个 32 位 RAW10 字、720 行及接收器 Lane Error；存储侧检查恰好 172800 个 128 位字，并等写命令全部被 DDR 控制器接收后，才发布该帧。
3. **显示与采集独立持有缓冲区**：四个槽位管理当前显示、最新完整帧和写入帧。旧显示读请求全部返回后，才在显示帧消隐阶段换槽；正在显示的槽和待显示槽都不会被写入覆盖。无新完整帧或捕获异常时，重复上一张有效画面。
4. **FIFO 保护**：输入溢出时丢弃本次捕获，下一帧重新对齐。输出按“已占用字数 + 未返回读请求”预留空间，禁止空读/满写。意外欠读时，本帧余下区域保持最近有效像素，下一显示帧清理并重同步；不会因此复位 DSI 屏。
5. **自动白平衡更平稳**：仅采用完整帧统计，要求至少 1/8 的抽样点可用，剔除暗部与饱和点；亮度统计突变超过约 25% 时暂缓更新。使用 1/16 平滑、Q10 8 单位死区、每次有效更新最大 8 单位增益步长；增益仍只在帧开始锁存。光源改变后收敛速度会比旧版慢。
6. **增益成组生效**：按 SC500CS 数据手册 V1.8 第 2.3 节，使用 `0x3800=0x00` 开始 Group0，写曝光和模拟增益，再以 `0x10` 结束、`0x40` 按帧生效。沿用传感器默认 `0x3817=0x20`（N=0）。在摄像头 SOF 同步后发起写入，每次写入之后至少间隔两个帧事件，忙时只保留最新目标。

坏帧重复显示会表现为短暂停留，这是保护行为。持续带宽不足时，输出保护仍可能留下短暂的局部停滞；是否解决你遇到的移动闪黑，需要实际开发板验证。

## 验证和上板复测

本包完成 RTL 仿真、TD 综合/布局布线、时序检查和 bitstream 生成；具体结果见 `BUILD_REPORT.md`、`build_evidence/`，源码和镜像对应关系见 SHA-256 清单。`verification/run_sim.ps1` 可用 Vivado XSIM 重跑测试。界面截图是 RTL 输出，左侧使用测试渐变图。

尚未连接实物板。请先下载新镜像，测试：

1. 确认下载的是带 `WB_FIX` 文件名的新镜像，启动后先检查实时预览是否恢复；随后用日光预设 + 4 倍增益，固定摄像头再左右移动各约 30 秒，观察是否还有整帧黑屏、闪现或撕裂。
2. 自动模式同样移动，再切换到不同光源，观察颜色是否平稳过渡；同时对比固定预设是否也出现异常。
3. 在感光度页面切换 1/2/4 倍，长按加减，再按实体按键，检查数值同步和画面变化；测试回退、长按进入、色温滑条。

如果仍异常，请提供一段同时包含固定和移动过程的屏幕录像，并注明当时的白平衡模式、倍率、供电方式和所用摄像头/屏幕版本。这些实测能区分剩余的传输、供电或成像控制问题。

**色温 LUT 保持上版演示初值，尚未用本机灰卡标定，绝对 K 值准确度不作保证。** 可通过 `user_source/hdl_source/wb/kelvin_gains_demo.csv` 和 `tools/compile_kelvin_lut.py` 替换标定表后重新构建。
